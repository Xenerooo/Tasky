# About Tasky

Tasky is a lightweight task and notes app built with React Native and Expo. It focuses on fast capture, simple organization, and local-first storage so you can manage tasks and notes offline.

Core technologies
- React Native + Expo
- TypeScript
- SQLite (local database)

Key features
- Tasks, notes, and timelines
- Calendar and inbox views
- Local persistence and seed data
- Theming and customizable components

Getting started
1. Install dependencies: `npm install` or `yarn`
2. Start the app: `npm start` or `expo start`
